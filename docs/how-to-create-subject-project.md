# 如何创建学科项目

这份文档只讲第一次把学科和项目建起来，并把本地学习材料导入到项目里的最小路径。

## 第 1 步：创建学科和项目

1. 打开系统后，先进入“学科中心”页面。
2. 点击“新建学科”。
3. 只填写学科标题，例如“机器学习”“英语听力”“操作系统”。
4. 填写学科标题后，点击“创建学科”。
5. 创建完成后，先进入“学科总面板”。
6. 系统会自动创建一个默认网课项目，直接点击这个项目卡片里的“项目设置”。

:::guide-demo scene="subject-project" state="create-subject" highlight="new-subject-button" title="创建学科和默认项目"
这个场景对应首次上手时从“学科中心”创建学科，并在创建后继续进入项目的入口。
:::

如果当前部署启用了浏览器本地素材访问，创建弹窗里会直接提示你：

`创建后请到项目设置中绑定本地素材目录，并手动同步目录内容。`

看到这个提示时，说明下一步不是去重启应用，而是先进入具体项目，再去“项目设置”。
如果你刚刚完成新建学科，可以直接使用系统自动创建的默认网课项目，不需要先进工作台。

---

## 第 2 步：到“项目设置”绑定目录

这是当前首次使用最关键的一步。

从新建学科引导进入时，你会直接打开默认网课项目的“项目设置”。如果你是手动操作，先进入具体项目，再打开“项目设置”。

1. 打开项目菜单里的“项目设置”。
2. 找到“本地素材目录”卡片。
3. 点击“选择并授权目录”。
4. 在浏览器弹出的目录选择器里，选中你的学习内容根目录。
5. 浏览器询问权限时，选择允许。
6. 回到页面后，确认“当前状态”已经变成“已授权”。

:::guide-demo scene="project-directory" state="unbound" highlight="authorize-button" title="绑定本地素材目录"
这个场景展示“项目设置”里的本地素材目录卡片，重点是先点击“选择并授权目录”。
:::

你可以把一个网课项目理解为“绑定到一个你自己管理的视频目录”。后面工作台左侧看到的学习对象，就是从这个目录导入出来的。

建议你提前按主题整理好目录，例如：

```text
机器学习/
  第1章/
    01-绪论.mp4
    02-线性回归.mp4
  第2章/
    01-逻辑回归.mp4
    02-决策树.mp4
```

请尽量避免在同一层目录里同时混放“子目录”和“裸文件”，这样学习对象树会更稳定。

---

## 第 3 步：同步目录内容

目录授权完成后，系统会自动同步一次当前目录内容。以后你新增、删除、重命名或移动视频文件时，也从这里手动同步。

操作顺序：

1. 仍然停留在“项目设置”页面。
2. 点击“同步目录内容”。
3. 等待页面提示同步或导入完成。
4. 再回到“工作台”或“学习对象树”页面查看结果。

:::guide-demo scene="project-directory" state="imported" highlight="import-button" title="同步目录内容"
这个场景展示目录授权完成后，同步按钮和完成状态如何帮助你确认学习对象树已经准备好。
:::

同步完成后，系统会做三件事：

1. 识别目录里的视频文件和目录层级。
2. 重建当前项目的学习对象树。
3. 为可播放的内容实例建立索引。

如果工作台左侧还是空的，优先检查这 4 件事：

1. 你是不是还没有点击“同步目录内容”。
2. “本地素材目录”的状态是不是仍然不是“已授权”。
3. 你选中的目录是不是当前项目真正要用的根目录。
4. 当前浏览器是不是不支持目录授权，或者曾经拒绝过权限。

## 常见问题

### 为什么左侧“学习对象”还是空的？

优先检查下面几项：

1. 你是否已经到“项目设置”点击过“同步目录内容”。
2. “本地素材目录”的状态是不是“已授权”。
3. 你选中的目录是不是确实包含当前项目要学的视频。
4. 当前浏览器是否支持目录授权。

### 为什么视频区域提示找不到本地文件？

最常见的原因是：

1. 你授权了错误的目录。
2. 文件后来被移动过。
3. 目录已经变了，但还没有重新同步目录内容。
4. 当前浏览器对这个站点的目录权限已经失效。

优先回“项目设置”重新授权或重新同步，不要先删除学科或项目。

## 一句话总结

创建学科项目的最小路径是：

`创建学科 -> 默认网课项目设置 -> 授权目录 -> 同步目录内容`

完成到这里后，再进入“如何学习复习”文档，从工作台开始录入复述点和完成复习。

# 如何使用 AI 问答

这份文档只讲项目里的 AI 问答最小使用路径：先准备学习对象和大模型能力，再进入项目的 AI 问答界面开始对话。

## 使用前先确认 3 个条件

AI 问答需要项目内容和可用的大模型服务同时准备好。

1. 当前项目已经在“项目设置”里绑定本地素材目录。
2. 当前项目已经同步目录内容，并且“结构视图”的“学习对象树”页签里能看到具体学习对象。
3. 当前账号或当前部署已经绑定第三方 LLM API；如果还没有，先到“全局设置”的“大模型配置”里保存 Base URL、模型名和 API Key。

如果这 3 个条件缺了任意一个，AI 问答页可能会提示没有上下文、没有可提问节点，或当前还没有接通可用的 LLM。

---

## 第 1 步：准备项目上下文

AI 问答会围绕项目里的学习对象或复习内容组织上下文，所以先确认项目内容已经进入系统。

1. 打开具体项目。
2. 进入“项目设置”。
3. 在“本地素材目录”里确认目录已经授权。
4. 点击“同步目录内容”。
5. 回到“结构视图”的“学习对象树”页签，确认能看到要学习的视频、章节或目录节点。

如果学习对象树还是空的，先回到“如何创建学科项目”文档检查目录授权和同步步骤，不要直接去 AI 问答页。

---

## 第 2 步：绑定第三方 LLM API

AI 问答不会在浏览器里直接保存第三方密钥，而是通过系统后端使用你保存的大模型配置。

1. 打开“全局设置”。
2. 找到“大模型配置”。
3. 填写兼容 OpenAI 接口的 Base URL。
4. 填写模型名。
5. 填写第三方 LLM API 的 API Key。
6. 点击“保存大模型设置”。
7. 保存成功后，再回到项目继续使用 AI 问答。

如果当前账号不是有效会员，页面可能会先显示会员门禁；这种情况下需要先处理会员状态，才能保存个人 LLM 配置和使用 AI 问答。

---

## 第 3 步：进入项目 AI 问答界面

准备好结构视图里的学习对象树和 LLM 后，就可以进入项目的 AI 问答界面。

1. 打开要提问的项目。
2. 点击项目左侧导航里的“AI问答”。
3. 系统会进入项目 AI 问答路由：`/p/:projectId/ai-chat`。
4. 在左侧学习对象目录里选择一个具体节点作为本轮上下文。
5. 确认页面显示当前上下文后，在输入框里输入问题并发送。

也可以从学习对象节点详情页点击“AI问答”进入，这样系统会直接带上当前学习对象作为上下文。

---

## 第 4 步：开始第一轮对话

第一次使用时，建议从范围清晰的问题开始。

可以这样问：

1. “请用更容易懂的话解释这个小节。”
2. “帮我梳理这个视频的核心概念和先后关系。”
3. “根据当前节点，给我 5 个适合复习的问题。”
4. “我对这里的概念有点混乱，请先问我几个检查理解的问题。”

AI 的回答只用于辅助理解，不会自动写入正式复述点。需要沉淀为复习内容时，回到工作台，把你确认过的内容整理成自己的复述点再提交学习。

## 常见问题

### 为什么输入框不能发送？

优先检查下面几项：

1. 当前项目是否有学习对象树。
2. 是否已经选择具体学习对象节点。
3. 第三方 LLM API 是否已经在“大模型配置”里保存成功。
4. 当前账号是否有使用 AI 问答的权限。
5. 当前模型服务地址、模型名或 API Key 是否填写正确。

### AI 回答可以直接当复述点吗？

不建议直接复制。

AI 问答适合帮你解释、拆解、追问和生成候选思路；正式复述点应该由你确认后再写入工作台。这样后续复习看到的是你真正理解过的内容，而不是未经检查的模型输出。

## 一句话总结

AI 问答的最小路径是：

`绑定本地素材目录 -> 同步出学习对象树 -> 在结构视图确认对象 -> 绑定第三方 LLM API -> 进入项目 AI问答 -> 选择上下文并开始对话`

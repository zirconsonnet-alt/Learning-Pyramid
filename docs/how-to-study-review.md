# 如何学习复习

这份文档只讲工作台里的学习复习闭环：录入复述点、提交学习、完成复习。
进入工作台后，按高亮位置完成录入复述点和做复习。
演示内容与真实学科、项目隔离。

## 第 5 步：在工作台录入复述点

项目内容识别出来以后，核心操作就在“工作台”。

按这个顺序做：

1. 在左侧“学习对象”区域里选中一个具体学习对象。
2. 中间会出现对应的视频播放器。
3. 播放到一个值得记忆的位置时暂停。
4. 点击“添加复述点”。
5. 锚点位置按当前播放时间记录；如需微调，可以直接把锚点改成 `17:57`、`1:02:03` 或 `t=1077104` 这类时间格式。
6. “问题”里是一条未来复习时看到的提示语，确认后点击“下一步”。
7. “答案”里是回忆后需要核对的复述内容，确认后点击“下一步”。
8. 如果这条复述点依赖之前已经录入过的复述点，在“问题”或“答案”输入框里按一次 `Tab`，继续输入关键字筛选候选，用方向键选中后再按一次 `Tab` 完成引用；已选引用会作为蓝色链接显示在答案区域。
9. 重复上面的动作，把当前项目里值得复习的关键点录进去。
10. 在下方填写“学习任务标题”。
11. 点击“提交学习”。

:::guide-demo scene="workbench-recall" state="editing-recall" highlight="recall-form" title="在工作台填写复述点"
这个场景对应选中学习对象、暂停视频、填写问题和答案，并提交学习任务的核心闭环。
:::

这里有几个实用建议：

1. 一个复述点只放一个清晰的记忆目标，不要把很多知识点塞进同一题。
2. 问题尽量写成你未来复习时能直接触发回忆的话，例如“线性回归的目标是什么”，而不是模糊标题。
3. 问题和答案可以直接写 Markdown 与 LaTeX 语法；录入或在复述点详情页编辑时，可以把鼠标放到字段后的“预览”上临时查看渲染效果，移开后回到编辑状态。复习、详情和推荐复习等只读展示场景会渲染格式，录入和编辑框里仍然显示原始文本，方便继续修改。
4. 引用只在确实存在前置依赖时再加；如果加错了，点击答案区域里的蓝色引用链接即可删除。复述点详情页的引用链接会显示被引用复述点的题面摘要，过长时以 `...` 截断。

## 第 6 步：做复习

有待完成的复习任务时，工作台中间区域会从“复述点录入”切换成“复习”。

复习时按这个顺序做：

1. 看题目，先自己回忆，不要急着看答案。
2. 在“你的答案”里写下自己的答案或复述内容，确认后点击“下一步”。
3. 点击“提交答案”，马上核对标准答案。
4. 如果完全想不起来，可以点击“跳过”，直接查看答案，再自己选择“记得”或“不记得”。
5. 根据自己的真实状态，点击“记得”或“不记得”。
6. 当前任务里所有题都判断完以后，点击“提交本轮复习”。

如果你看到“队列非空时禁止提交学习”，这是正常门禁，不是报错。意思是：

你当前还有待完成的复习，所以要先把复习做完，再继续提交新的学习任务。

## 推荐的学习复习节奏

如果你不确定应该怎么安排，直接照下面这套最稳：

1. 先确认项目已经完成目录授权和内容同步。
2. 回到工作台，确认左侧已经出现学习对象。
3. 选一个视频，录入一组复述点并提交学习。
4. 先把待完成的复习做完。
5. 确认整条流程跑通后，再继续录入下一批项目内容。

这样做的好处是：视频可播放性、复述点录入、学习提交和复习链，都会在最早阶段就被验证出来。

## 常见问题

### 为什么“提交学习”按钮点不了？

常见原因有 4 个：

1. 还没有填写学习任务标题。
2. 还没有添加任何复述点。
3. 某个复述点的“问题”或“答案”还是空的。
4. 当前还有待完成的复习任务。

### 内容文件换了位置怎么办？

如果只是重命名、移动目录或替换了文件：

1. 先回“项目设置”重新同步目录内容。
2. 如果旧实例还有复述点锚点，它会变成缺失实例，再到“缺失内容修复”里处理锚点迁移；没有复述点引用的旧实例会在同步时清理掉。

不要直接删除旧学科或项目重来，否则旧复述点的锚点关系也会一起丢失。

## 一句话总结

学习和复习的最小闭环是：

`选择学习对象 -> 录入复述点 -> 提交学习 -> 完成复习`

只要这条路径跑通，后面的推荐复习、复习链和上推结构就都能顺着理解下去。

# 如何使用番茄钟

这份文档只讲番茄钟的最小使用路径：开启番茄钟，设定计划，绑定项目，然后在学习时间进入工作台。

## 会员状态

番茄钟是会员功能。

1. 如果当前账号还没有有效会员，先进入“会员中心”开通会员。
2. 开通后回到“番茄钟”页面继续。

---

## 第 1 步：开启番茄钟

如果番茄钟还没开启，先在“番茄钟”页面打开它。

1. 打开左侧导航里的“番茄钟”。
2. 点击“开启番茄钟”。

如果只是立刻体验一次，可以使用快速番茄；如果希望每天按固定时间开始，就继续设定番茄计划。

---

## 第 2 步：设定番茄计划

番茄计划决定什么时候开始、每段学多久，以及每个番茄绑定到哪个具体项目。

1. 在“番茄钟”页面点击“新增计划”。
2. 选择计划生效的星期、开始时间、学习分钟、休息分钟和番茄数量。
3. 为计划中的番茄绑定学科项目。
4. 保存计划。

建议第一次只设一个离当前时间较近的计划，用来确认开关、跳转和项目绑定都能正常工作。

---

## 第 3 步：进入工作台学习

学习时间开始后，从番茄钟进入绑定项目的工作台。

1. 到计划开始时间前，先打开并登录网页。
2. 保持浏览器标签页打开。
3. 番茄开始后，进入“番茄钟”页面查看当前状态。
4. 如果这个番茄已经绑定项目，进入对应项目的工作台。

如果计划已经到了开始时间，但你还没有登录网页，系统无法替你在离线状态下打开工作台。此时登录网页后，先进入“番茄钟”查看当前计划状态，再进入正在进行的项目工作台。

## 常见问题

### 为什么到了时间没有自动进入工作台？

优先检查下面几项：

1. 当前账号是否有有效会员。
2. 番茄钟总开关是否已经开启。
3. 今天是否有启用中的番茄计划。
4. 当前计划是否已经绑定学科下的具体项目。
5. 你是否已经登录网页，并保持浏览器标签页打开。
6. 当前是否正在休息时间，而不是学习时间。

### 可以不绑定项目吗？

排程番茄可以暂时不绑定，但不推荐长期这样用。

未绑定项目的番茄会继续计时，但系统无法自动进入具体工作台，也不能把这一段学习明确归到某个项目。建议至少在正式学习前，把每个番茄绑定到当天要推进的项目。

快速番茄要求先选中学科下的具体项目：只有当前选中的是学科下的具体项目时，系统才会把这次小番茄绑定到该项目；如果没有选中具体项目，需要先进入具体项目工作台再新建小番茄。

## 一句话总结

番茄钟的最小路径是：

`会员有效 -> 开启番茄钟 -> 设定番茄计划 -> 绑定项目 -> 进入工作台学习`

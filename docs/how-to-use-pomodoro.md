# 如何使用番茄钟

这份文档只讲番茄钟的最小使用路径：先开启番茄钟，再设定番茄计划，最后在番茄开始后登录网页进入学习。

## 第 1 步：先开启番茄钟

如果你还没有开启番茄钟，先完成这一步。

1. 打开左侧导航里的“番茄钟”。
2. 如果页面提示番茄钟未开启，进入“番茄钟设置”。
3. 打开番茄钟开关。
4. 按需确认提示音、间歇提醒和休息音乐等设置。
5. 回到番茄钟页面，确认页面不再显示“未开启”状态。

如果你只是想立刻体验一次，可以先使用快速番茄；如果你希望每天自动按固定时间开始，就继续设定番茄计划。

---

## 第 2 步：设定番茄计划

番茄计划决定系统什么时候开始、每段学多久，以及每个番茄绑定到哪个学科下的具体项目。

1. 在“番茄钟”页面点击新建或编辑计划。
2. 选择计划生效的星期。
3. 设置开始时间。
4. 设置单个番茄的学习分钟、休息分钟和番茄数量。
5. 先选择学科，再为每个番茄绑定该学科下要学习的具体项目；如果暂时没有绑定项目，番茄仍会计时，但不会自动切入具体项目工作台。
6. 保存计划。

建议第一次只设一个离当前时间较近的计划，用来确认开关、跳转和项目绑定都能正常工作。确认流程跑通后，再补全天或整周的计划。

---

## 第 3 步：番茄开始后登录网页

番茄钟的学习时间由网页端执行，所以计划开始前后要让网页处于可用状态。

1. 到计划开始时间前，先打开并登录网页。
2. 保持浏览器标签页打开。
3. 番茄开始后，进入“番茄钟”页面查看当前状态。
4. 如果这个番茄已经绑定项目，点击或等待系统进入对应项目的工作台。
5. 进入工作台后，只在当前番茄绑定的项目里学习，直到系统进入休息时间。

如果计划已经到了开始时间，但你还没有登录网页，系统无法替你在离线状态下打开工作台。此时登录网页后，先进入“番茄钟”查看当前计划状态，再进入正在进行的项目工作台。

## 常见问题

### 为什么到了时间没有自动进入工作台？

优先检查下面几项：

1. 番茄钟总开关是否已经开启。
2. 今天是否有启用中的番茄计划。
3. 当前计划是否已经绑定学科下的具体项目。
4. 你是否已经登录网页，并保持浏览器标签页打开。
5. 当前是否正在休息时间，而不是学习时间。

### 可以不绑定项目吗？

可以，但不推荐长期这样用。

未绑定项目的番茄会继续计时，但系统无法自动进入具体工作台，也不能把这一段学习明确归到某个项目。建议至少在正式学习前，把每个番茄绑定到当天要推进的项目。

快速番茄也遵循同样规则：只有当前选中的是学科下的具体项目时，系统才会把这次小番茄绑定到该项目；如果没有选中具体项目，小番茄会按未绑定项目计时，不会锁定某个工作台。

## 一句话总结

番茄钟的最小路径是：

`开启番茄钟 -> 设定番茄计划 -> 番茄开始后登录网页 -> 进入工作台学习`

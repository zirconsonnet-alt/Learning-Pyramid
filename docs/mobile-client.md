# 移动端客户端

本文记录 Android 和 iPhone App 的当前确认边界。移动端客户端采用 React Native，不是移动端网页适配，也不是 WebView 包壳。

## 当前阶段

当前阶段目标是创建第一版移动端 MVP：

- 使用 Expo-managed React Native。
- 新增独立移动端工程 `mobile/`。
- 默认连接线上 API：`https://plm.xuebao.chat/api`。
- 复用现有 FastAPI API envelope、认证语义和 scoped project 语义。
- 使用移动端原生 UI 重新实现核心学习流程。

当前仓库已包含 `mobile/` Expo 应用预览。当前实现包含：

- 登录、会话恢复和退出。
- 学科中心：学科列表、新建学科、删除学科、进入项目中心，以及独立学科设置页的学科名称保存；无学科时显示“开始学习”初始化状态，不展示项目级底部导航。
- 项目中心：学科下项目列表、新建项目、删除项目和进入工作台；有学科但无项目时显示“暂无项目”初始化状态，并保留学科设置入口。
- 项目 Shell：进入有效 scoped project 后，不再显示额外“工作台”原生标题栏或项目内返回按钮；顶部只显示当前“学科 · 项目”上下文，点击标题打开上下文 bottom sheet；底部提供“学习 / AI / 复习 / 结构 / 我的”五个任务入口。
- 全局设置：当前账号的大模型配置、语音识别配置和主题偏好保存；服务密钥清除必须通过独立清除动作触发，普通保存不会把空密钥当作新值提交。
- 我的：账号与系统级入口，包含个人中心、好友中心、会员中心、用户指南、全局设置、后台管理和退出登录；学科设置和项目设置不作为“我的”的主入口。
- scoped project 原生移动工作台：默认进入当前学习对象，首屏优先展示当前内容、锚点、媒体区域和紧凑快捷操作；当前视频名承担学习对象切换入口，学习统计以网页端同层级结构平铺在媒体下方，包含预计剩余学习时长、观看覆盖和今日回看分解；支持媒体播放、桌面工作台语义的复述点录入 / 复习任务模式，以及层推进与学习任务模式。
- 后端 playback descriptor 媒体播放；当前移动端明确不支持 `NATIVE_LOCAL`、`BROWSER_LOCAL` 和 `MANUAL` 播放来源。
- 实例字幕读取、导入和播放器字幕叠加显示；用户导入的字幕资产优先于同目录同名字幕。
- 复述点草稿使用 rich content 数据结构、任务标题、可编辑锚点、答案引用和 `learning task` 提交；当前原生 UI 只提供文本录入，不提供图片块上传。
- 队列头复习任务在工作台内展示：先写自己的答案，提交或跳过后显示标准答案，再选择“记得 / 不记得”，可追加理解后提交。
- 层推进与学习任务：读取层级、待推进 aggregation queue、学习任务节点，支持手动上推；阈值上推策略下支持开关阈值自动上推。
- 项目 AI：读取系统 LLM 能力状态，围绕当前学习对象或学习任务节点调用 scoped project LLM ask。
- 复习推荐：读取项目推荐复习列表，支持先写自己的答案、展开答案，并在本地会话中标记“记得 / 不记得”。
- 结构视图：在项目内切换学习任务树和学习对象树，使用移动端原生层级列表展示。
- 移动端 API client、认证状态、领域 API、导航、工作台、媒体、草稿、内嵌复习、推荐复习、AI 问答、结构视图和层推进测试。

当前阶段不包含：

- 手机本机文件导入。
- 手机工作台内的百度网盘素材导入入口。
- 手机端百度网盘账号绑定 / OAuth 回调。
- 手机端项目设置里的本地目录绑定、百度网盘导入、缺失素材修复和高级层级模板编辑。
- 手机端 AI 问答的流式输出、会话历史管理、视频帧上下文和网页端完整侧栏能力。
- 手机端复习推荐的图片作答和推荐阈值调整。
- “我的”中的个人/好友/会员/用户指南/后台详情页完整功能；当前这些入口只确认导航归属或显示明确不可用状态。
- 通用离线缓存。
- Windows Tauri `NATIVE_LOCAL` 数据流迁移。
- WebView 包壳。
- Android / iOS 原生裸工程维护。
- 移动端专用后端协议。

## 功能边界

第一版移动端工作台按桌面/网页工作台语义实现学习主流程：

- 登录、获取当前用户、退出。
- 学科中心内创建、删除和进入学科。
- 学科设置内重命名学科。
- 项目中心内创建、删除和进入学科项目。
- 项目 Shell 内保留当前学科/项目上下文，并在项目存在后提供学习、AI、复习、结构和我的五个移动端任务入口。学科/项目切换、学科设置、项目设置、学科中心和项目中心属于上下文管理，不能作为学习页正文首屏按钮区。
- 项目设置作为当前项目的对象级入口存在；当前移动端项目设置详情能力仍是占位，不承载本地目录绑定、百度网盘导入或缺失素材修复。
- 全局设置内维护当前账号的大模型、语音识别和主题偏好。
- 进入学科材料对应的 scoped project。
- 在项目内默认进入学习优先工作台，而不是只停留在对象列表。
- 通过当前视频名打开学习对象切换列表。
- 获取已有本地/服务端课程视频或音频播放描述符并播放。
- 导入 `.srt`、`.vtt`、`.ass`、`.ssa` 字幕文件并绑定当前课时实例；播放时使用统一字幕接口显示当前字幕片段。
- 录入学习任务标题。
- 新建 rich content 复述点草稿；COURSE 项目按当前播放时间生成 `t=<毫秒>` 锚点，并允许编辑为 `17:57`、`1:02:03` 或 `t=<毫秒>`。
- BOOK 项目使用文本锚点；LOOSE_POINTS 项目不要求学习对象或锚点。
- 为答案添加已有复述点引用，并将当前草稿提交为一个 `learning task`。
- 队列非空时在工作台内进入复习任务，提交带 `canRecall` 和追加理解的复习结果。
- 通过复习 tab 进入推荐复习，使用 `/review-recommendations` 读取当前批次并完成本地会话作答。
- 通过 AI tab 进入项目问答，使用 `/system/capabilities` 判断 LLM 状态，并使用 scoped `/llm/ask` 围绕当前学习对象或学习任务节点提问。
- 通过结构 tab 查看学习任务树和学习对象树。
- 查看层推进与学习任务，触发既有层级上推 API。

移动端不扫描手机系统文件，也不写手机公共目录。移动端允许通过电脑端配对导入 App 托管的离线课程包；离线课程包必须绑定线上学科和 scoped project。手机本地播放只使用 App 私有课程库内已校验文件。删除本地课程包只删除手机本地素材，不删除线上学习记录。

手机工作台当前不暴露百度网盘素材导入入口；如果后续要在移动端提供该能力，需要先单独确认入口位置和导航边界，不能把导入流程塞回学习工作台。手机端账号连接、通用离线缓存、推送提醒、支付和发布渠道的能力，需要后续单独确认边界后再实现。移动端导航按作用域分层：学科设置属于当前学科，项目设置属于当前项目，全局设置和账号/系统入口属于“我的”。学习页正文只承载当前学习内容和当前项目任务，不承载上下文管理路由平铺。

## 数据流

移动端请求数据流固定为：

```text
React Native App -> HTTPS -> FastAPI /api -> SystemAPI -> 持久化 store
```

移动端必须使用现有公开 HTTP API：

- `/api/auth/*` 用于认证。
- `/api/subjects` 和 `/api/subjects/{subjectId}` 用于学科列表、创建、重命名和删除。
- `/api/subjects/{subjectId}/materials` 和 `/api/subjects/{subjectId}/materials/{materialId}` 用于学科项目列表、创建和删除。
- `/api/profile/me/llm-settings`、`/api/profile/me/asr-settings` 和 `/api/profile/me/global-settings` 用于全局设置。
- `/api/system/capabilities` 用于判断移动端 AI 问答是否有可用 LLM。
- `/api/subjects/{subjectId}/projects/{scopedProjectId}/...` 用于项目内学习对象、学习任务节点、媒体播放、复述、复习、结构和 AI 问答。
- `/api/subjects/{subjectId}/projects/{scopedProjectId}/instances/{instanceId}/subtitle-file` 用于读取、上传和删除实例字幕资产。

移动端不直接访问后端 repository、内部 project id 或私有 helper。公开 scoped project id 仍必须由后端 `resolve_scoped_project()` 边界解析。

全局设置仅复用当前账号已有 profile/system 配置语义。会员限制、未授权、服务未配置等状态由后端按现有错误返回，移动端不新增兼容入口或特殊分支。

## 认证边界

第一版移动端沿用现有登录 API。移动端本地会保存会话所需的认证状态，但不引入新的认证协议。

百度网盘账号绑定仍沿用网页/桌面个人中心的浏览器 OAuth 流程。移动端当前不承载 OAuth 回调，也不在工作台读取百度网盘账号或目录，不新增移动端 token 或认证分支。

如果实现阶段发现浏览器 cookie 会话不能在 React Native 中稳定承载移动端登录态，必须暂停确认认证策略。可选方向包括继续 cookie 会话、增加明确的移动端 token 会话，或调整后端 cookie 策略；不能通过隐式 header、特殊分支或临时兼容层绕过认证边界。

## 媒体边界

移动端只播放后端返回的已有播放描述符。第一版不实现：

- 手机本机路径播放。
- 手机本机字幕扫描。
- 手机本机字幕生成或 ASR 转写。
- 百度网盘本机代理。
- 通用离线缓存。
本地课程包是项目级 App 私有素材库，不是手机系统文件扫描，也不是公共目录缓存。

如果某类 `PlaybackDescriptor` 的 `url` 或 `playbackKind` 在移动端播放器中不可用，应上报为媒体能力缺口，不应在前端添加未确认的 fallback 播放路径。

当前移动端播放器使用 `expo-video`。支持路径限于后端 descriptor 能直接给出的 `SERVER_FS` URL，以及 App 私有离线课程包校验后的 `LOCAL_COURSE_PACKAGE` 文件 URI；`BAIDU_NETDISK` 当前作为隐藏媒体源显示不可播放状态，`NATIVE_LOCAL`、`BROWSER_LOCAL` 和 `MANUAL` 也会显示明确不可播放状态。服务端媒体请求会携带当前 `plm_session` Cookie header，本地课程包播放不携带服务端 Cookie。

字幕显示不依赖 `expo-video` 原生字幕轨。移动端通过统一字幕 API 读取实例字幕资产，按当前播放进度在 React Native 层叠加显示。导入字幕使用系统文件选择器读取字幕文本并上传到后端；移动端不扫描手机目录，也不生成字幕。

真实 Android/iOS 环境中，受保护 HLS/文件资源是否能稳定通过原生播放器 header 访问，仍需要 emulator 或真机 smoke 验证。

## 本地运行

```powershell
pnpm --dir mobile install
$env:EXPO_PUBLIC_API_BASE_URL = "https://plm.xuebao.chat/api"
pnpm --dir mobile start
```

常用验证：

```powershell
pnpm --dir mobile test
pnpm --dir mobile typecheck
```

## 工程边界

移动端工程应保持独立：

- `mobile/` 承载 Expo 应用、移动端页面、移动端 API client 和移动端测试。
- `frontend/` 继续承载 Web/Tauri 复用的 React DOM UI。
- 后续如要共享类型或 API schema，应先确认共享包边界，不能从移动端直接引用 Web 专用组件或 Vite 专用模块。
- 根布局使用 Expo Router `Stack` 承载页面导航和系统返回手势；不能退回只用 `Slot` 直出页面。

移动端原生工作台不从 `frontend/` 复用 React DOM 工作台组件，但功能语义以桌面/网页工作台为准：选内容、播放器学习、复述点草稿、提交 `learning task`、复习门禁。移动端只改变交互布局，不新增移动端专用学习协议。

移动端学科中心、项目中心、学科设置、项目设置占位页、“我的”和全局设置也是独立 React Native 页面，不从 Web 设置页复制组件。后续如要补项目设置的本地目录、百度网盘导入或缺失素材修复，需要先确认对应移动端入口和原生能力边界。

## 验证边界

第一版移动端最小验证应覆盖：

- TypeScript 类型检查。
- API client envelope 解析测试。
- 登录态状态机或认证存储测试。
- Android 本地启动 smoke。

iPhone 真机、TestFlight、App Store、Android release 签名和应用商店发布不属于当前阶段验收。

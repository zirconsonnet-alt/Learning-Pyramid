# Current Change

更新时间：2026-05-14

## 1. 当前用户要求

- 以番茄计划详情页风格为基准，让番茄钟设置页向它靠拢。
- 目标是番茄钟设置页不再像孤立页面，番茄钟主页面保持不变。

## 2. 本次实际修改文件

- `frontend/src/views/pomodoro/PomodoroSubpageFrame.tsx`
- `frontend/src/views/pomodoro/PomodoroPage.tsx`
- `frontend/src/views/pomodoro/PomodoroSettingsPage.tsx`
- `frontend/tests/e2e/pomodoro-settings.spec.ts`
- `docs/current-change.md`

## 3. 每个文件为什么修改

- `PomodoroSubpageFrame.tsx`：新增番茄钟子页面共享外壳，统一壁纸背景、页面容器宽度、外层层级和间距。
- `PomodoroPage.tsx`：让番茄计划详情页使用共享子页面外壳；主页面仍保留原来的番茄钟页面容器。
- `PomodoroSettingsPage.tsx`：让设置页使用共享子页面外壳，并把标题区、返回按钮和容器宽度调整到计划详情页同一风格。
- `pomodoro-settings.spec.ts`：补充回归断言，确认番茄计划详情页和番茄钟设置页使用同一子页面容器宽度。
- `docs/current-change.md`：覆盖为本次任务工作单。

## 4. 行为语义是否变化

- UI 语义变化：番茄钟设置页现在按番茄计划详情页的子页面风格呈现。
- 功能语义不变：壁纸读写、休息音乐目录、随机微休息、默认提示词保存和计划详情编辑逻辑不变。
- 路由语义不变：`/pomodoro`、`/pomodoro/settings`、`/pomodoro/plans/:planId` 不变。

## 5. 是否做了重构，以及为什么

- 是，做了局部 UI 结构重构。
- 原因是设置页和计划详情页原本各自维护外层页面壳，导致宽度、返回区和壁纸容器容易继续分叉；抽出共享外壳能把番茄钟子页面边界显式化。

## 6. 未修改哪些相关内容，以及为什么

- 未修改番茄钟主页面，因为用户明确目标是两个子页面统一，主页面不作为本次基准。
- 未修改计划详情页内部表单、按钮和排程逻辑，因为它是本次风格基准。
- 未修改壁纸存储、账号隔离、休息音乐目录和提示词保存逻辑，因为本次问题是页面风格和外壳分叉，不是数据流问题。

## 7. 是否影响 API、架构、部署、数据结构、UI、测试

- API：否。
- 架构：否。
- 部署：否。
- 数据结构：否。
- UI：是，设置页外层风格向计划详情页靠拢。
- 测试：是，新增子页面容器宽度一致性的 e2e 断言。

## 8. 当前风险点和不确定项

- 当前统一的是子页面外壳、标题区、返回区和容器宽度；设置页内部内容仍保留自己的设置项结构，不强行改成计划详情页的业务表单布局。
